Automatic P40 – setup and help

This page explains exactly what P40 handles automatically, what Apple requires you to configure in Shortcuts, and how to change the setup later.

In short: You create two time automations in Apple Shortcuts. P40 then handles arrival verification itself using a local 1 km safety zone around Sluppenvegen 17A. The geofence never books parking by itself.

What does P40 do, and what do you do yourself?

P40 handles automatically

  • provides Activate P40 and Release P40 if not arrived actions to Shortcuts
  • stores the start time and weekdays selected in P40
  • creates a safety candidate only when a scheduled run actually creates a new P40 parking session
  • monitors arrival within a fixed 1 km zone around Sluppenvegen 17A when Automatic P40 is enabled and Always location access is granted
  • performs a new, fresh location check before any automatic release
  • keeps parking if location, sign-in, network or parking status is uncertain
  • shows local status for the last run and result

You configure in Shortcuts

  • the time automation that starts P40
  • the time automation that runs the safety check at least two hours later
  • the same time and weekdays shown by P40
  • permission for the shortcuts to run while the phone is locked
  • updated time triggers if you later change the start time or weekdays in P40

Before you start

1

Sign in to Parkeringsassistent P40 and select the correct vehicle.

2

Open Set up / change automation in P40.

3

Select the start time and weekdays, then enable Automatic P40.

4

Grant P40 Always location access and allow notifications.

Step 1 – create “P40 Start”

Purpose: starts the parking request at your selected time.

  1. In the P40 setup guide, tap Create in Shortcuts for Start P40.
  2. Find the P40 action Activate P40 and use it in a new shortcut.
  3. Name the shortcut P40 Start.
  4. In Shortcuts choose Edit → Automation and add Time of Day.
  5. Use the start time and weekdays shown by P40.
  6. Open Info → Privacy and enable Allow Running When Locked.
  7. Save, return to P40 and confirm that the setup matches.

Step 2 – P40 handles arrival itself

You do not need a separate arrival automation in Shortcuts. After an automatic booking is actually created, P40 uses a local 1 km safety zone around Sluppenvegen 17A.

When the phone enters the zone, P40 verifies the position and records arrival for that booking. This is only a safety check: entering the 1 km zone without an active automatic booking never starts parking.

Step 3 – create “P40 Frigi”

Purpose: checks whether an automatically booked space is still unused.

  1. In the P40 setup guide, tap Create in Shortcuts for Release unused space.
  2. Find Release P40 if not arrived.
  3. Name the shortcut P40 Frigi.
  4. Choose Edit → Automation → Time of Day.
  5. Use the control time shown by P40. It is at least two hours after the selected start time.
  6. Use the weekdays shown by P40. If the control time crosses midnight, P40 shows the days on which the control actually needs to run.
  7. Enable Allow Running When Locked, save and confirm the setup in P40.

What happens at the two-hour safety check?

Arrival already recorded: parking is kept.
The phone is currently inside 1 km: arrival is recorded and parking is kept.
iOS has already reported that the phone entered the 1 km zone: P40 keeps parking even if an exact GPS verification was unavailable at that moment.
The phone is safely outside 1 km: P40 can continue only if it can also confirm that the 1 km arrival monitor was actually armed after booking. It then verifies that the same vehicle still has the active P40 parking session before any release.
The 1 km arrival monitor was not confirmed active: P40 does not release. You receive a notification with booking time and control time and can stop manually if the space is not being used.
Always location access is missing: P40 does not release. You receive a notification containing both the booking time and the time the safety check ran.
GPS, network, sign-in or parking status is uncertain: P40 does not release.
Fail-safe: P40 prefers keeping a potentially unused parking session over stopping parking when the safety requirements cannot be verified.

Do you have an older setup with “P40 Ankomst”?

Build 54 no longer requires a separate arrival Shortcut. The older action remains available for backward compatibility so an existing setup does not suddenly stop working. Once the Build 54 setup is configured, P40 Ankomst is not required by the new automation flow.

When you change the start time or weekdays

  1. Change the value in P40.
  2. P40 marks which of the two Shortcuts need to be updated.
  3. Tap Edit / verify in Shortcuts. P40 opens the named shortcut as far as Apple's supported URL integration allows.
  4. Choose Edit → Automation in Shortcuts and update the time trigger to the values shown by P40.
  5. Return to P40 and confirm the setup again.

Apple does not give third-party apps access to read or modify a Personal Automation trigger directly. P40 therefore cannot inspect Apple's automation list or silently change the trigger time in the background.

“Shortcuts and status” in P40

The status screen shows P40's own knowledge: the setup you last confirmed, the last observed execution of the P40 action and the last recorded result. An observed run does not prove which Apple trigger launched it.

If location access is not granted

Automatic P40 may still have created parking through P40 Start, but P40 will not stop it automatically without a safe location check. At the safety check you are notified of the booking time and control time, and told to stop the parking session manually if you are not parked at P40.

Privacy

Location is processed locally on the device to calculate distance to Sluppenvegen 17A. The GPS coordinate is not sent to the parking service or the developer by this feature and is not stored as parking history. P40 stores limited local automation state, including booking time, vehicle registration number, optional verified arrival time and the latest safety check.

Official Apple Shortcuts documentation

The setup above follows Apple's current Shortcuts model for iPhone. Apple may change the names or placement of controls in later iOS versions.
